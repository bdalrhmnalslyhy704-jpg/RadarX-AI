Background monitoring:
- Android foreground service remains active in offline mode and reports that live market discovery is paused until validated connectivity returns.
- Android network callback triggers an immediate scan on reconnect.
- Falcon Eye reads its own durable event feed and cursor, independent of the combined radar feed.
- Alert events are persisted locally before notification delivery; pending alerts survive service/process restarts.
- Alerts replay in original detection order after outages and notifications report the original detection timestamp and recorded detection price, separately from phone delivery time.
- No live prices or discoveries are fabricated while the phone has no internet connection.

Release gate: source/JavaScript tests, Falcon Eye API contract, Railway health, signed universal APK verification, Android offline-to-online smoke test, and HTTPS download SHA-256 integrity check.

Smoke gate note: release build statically validates RadarXBackgroundMonitorService, FOREGROUND_SERVICE_DATA_SYNC, and ACCESS_NETWORK_STATE from the manifest. MainActivity starts the native foreground monitor directly from onCreate, independently of WebView readiness, and retains a delayed retry. Service-running detection now uses process-local state instead of trusting a stale SharedPreferences bit, so an Android force-stop cannot block a future restart. Monitoring does not wait for POST_NOTIFICATIONS permission; visible notifications still require the user to allow them. The CI smoke test makes emulator permission grant best-effort, verifies native startup/service-ready logs, checks offline waiting and process liveness, then checks resumption after validated Internet returns.
