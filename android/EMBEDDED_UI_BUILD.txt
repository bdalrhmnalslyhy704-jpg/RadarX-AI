TRADLI 1.6.0:
- Native dashboard entry is smoke-tested through the visible accessibility target, not a guessed screen coordinate.
- Backend proxy is HTTPS allow-listed and GET-only; backend failures are logged without exposing secrets.
- Connection diagnostic checks health, readiness, and the actual Market Radar data route. Each module exposes actionable error details instead of claiming success on a failed request.
- Chart Lab renders real OHLC candles returned by the backend for 15m, 1h, and 4h; the page rejects open/future candles. Uploaded chart images are previewed locally and are not falsely described as AI-analyzed.
- Verify and Advisor use a live deep scan; Signals Hub reads saved RadarX alerts; Supply/Demand shows backend-derived support/resistance; Order Desk calculates and copies a paper-only plan without sending orders.
- Cached/stored market responses are not accepted as proof of current live data for decision checks.

Background monitoring:
- Android foreground service remains active in offline mode and reports that live market discovery is paused until validated connectivity returns.
- Android network callback triggers an immediate scan on reconnect.
- Falcon Eye reads its own durable event feed and cursor, independent of the combined radar feed.
- Alert events are persisted locally before notification delivery; pending alerts survive service/process restarts.
- Alerts replay in original detection order after outages and notifications report original detection time and detection price separately from phone delivery time.
- No live prices or discoveries are fabricated while the phone has no Internet connection.

Release gate: JavaScript/source tests, Falcon Eye API contract, Railway health, signed universal APK verification, Android online/offline/reconnect + TRADLI launch smoke test, and HTTPS APK checksum verification.
Safety: Spot/Paper/read-only only; no account, order, or withdrawal endpoints; no API keys in the APK.
